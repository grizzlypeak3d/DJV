Every menu item, with its default keys and the name of its command, as the application reports them. The descriptions are the items' tooltips. This page is made from the application itself, so it lists exactly what the version it was made from has.

Ctrl/Cmd is Command on macOS and Control elsewhere; Ctrl is Control everywhere. The keys can be changed in the Shortcuts section of the Settings tool.

The commands are how the menu items are run from outside the window: with -command on the command line, and from Python. Commands that take a value say so.

Commands without a menu item

For scripts and the command line.

CommandDescription
Debug/StateWrite the live model state as JSON, to a file or standard output; e.g., { "file": "state.json" }.
Export/MovieExport the current file as a movie with the Export tool's settings, changing any given first; e.g., { "dir": "/tmp", "fileName": "out", "ext": ".mov", "preset": "APV 422", "audioCodec": "Auto", "overwrite": true, "exit": true }. "exit" quits once the movie is written or has failed.
File/LayerSet a file's layer by name or index, e.g., { "layer": "diffuse" }. It is the "A" file's unless "file" gives the index of another in the file list.
File/MediaReferenceSet a file's media reference by name, e.g., { "key": "Proxy" }; "As Authored" or an empty key is the references the clips were authored with. It is the "A" file's unless "file" gives the index of another in the file list.
Playback/InOutRangeSet the playback in/out range from inclusive frames relative to the timeline start; e.g., { "in": 10, "out": 50 }.
Playback/SeekSeek to a frame, relative to the timeline start; e.g., { "frame": 100 }.
Timeline/ZoomZoom the timeline, in pixels per second, keeping the current frame in place; e.g., { "value": 100 }.
