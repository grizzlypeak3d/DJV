Setup verbs for interaction, in addition to open/tool/expand/tab/pick/zoom:
* { "click": "Files.CompareMode" } clicks the widget with that screenshot
  tag; { "click": "MainWindow.Viewport", "button": "Right" } right clicks
  it, which is how transient state -- a context menu, a popup -- gets into
  a capture. The [x, y] form clicks a framebuffer position.
* { "key": "Escape" } presses a key through the window's dispatch.
* { "drag": ["Files.FileThumbnail0", [1343, 350]] } presses at the first
  point, moves through the rest, and releases -- for drag and drop, or a
  slider. Each entry is a screenshot tag, whose widget's center is used,
  or a framebuffer position.

Configuration:

Requirements:
* Pillow for make_svg.py: python3 -m pip install Pillow

Example for building the screenshots:
% python3 etc/Screenshots/build_screenshots.py etc/Screenshots/screenshots.json --djv ../build-Debug/bin/djv/djv

Example for running a local server to preview the docs:
% brew install ruby
% export PATH="/opt/homebrew/opt/ruby/bin:$PATH"
% cd docs && bundle install
% cd docs && bundle exec jekyll serve --livereload
